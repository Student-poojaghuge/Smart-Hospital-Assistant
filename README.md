# 🏥 Smart Hospital Assistant

## AI-Powered Healthcare & Emergency Decision Support System

Smart Hospital Assistant is a final-year AIML project designed to provide
preliminary health risk assessment, emergency risk detection, doctor
consultation support, medicine information, appointment management and
AI-powered medical assistance.

## 🎯 Objectives

- Preliminary health risk assessment
- Emergency risk detection
- Doctor consultation support
- Medicine information
- Appointment management
- AI-powered medical assistance
- Hospital analytics

## 🤖 AI Modules

- Disease Risk Prediction
- Emergency Risk Assessment
- Appointment No-Show Prediction
- Explainable AI
- Medical RAG Assistant

## 🛠️ Technologies

- Python
- Streamlit
- FastAPI
- Scikit-learn
- XGBoost
- Pandas
- NumPy
- SQL
- PostgreSQL
- FAISS
- Sentence Transformers
- SHAP

## ⚠️ Medical Disclaimer

This project is an academic and decision-support prototype.
It does not replace professional medical diagnosis, treatment,
or emergency medical services.
